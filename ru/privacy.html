Политика конфиденциальности

English

Приложение ScheduleWidget для Android (пакет com.local.schedulewidget) · обновлено 25 ноября 2026 г.

Здесь описано, какие данные читает приложение ScheduleWidget, зачем, куда они попадают и как отозвать доступ. Политика относится и к приложению, и к страницам этого сайта. Приложение личное, у него один пользователь — автор. Учётных записей, регистрации, рекламы и аналитики нет.

1. Какие данные читает приложение

  • Календарь устройства (разрешение READ_CALENDAR) — названия событий, время начала и окончания, признак «весь день», цвета и названия календарей. Нужно для строк событий в виджете.
  • Контакты устройства (разрешение READ_CONTACTS) — только имена и даты контактов, у которых заполнено поле дня рождения. Нужно для строк дней рождения. Номера телефонов, адреса и другие поля контактов не запрашиваются.
  • Google Tasks (разрешение https://www.googleapis.com/auth/tasks.readonly) — названия задач, заметки, сроки и признак выполнения для незавершённых задач в списках пользователя. Нужно для строк задач.
  • Список календарей Google (разрешение https://www.googleapis.com/auth/calendar.calendarlist.readonly) — названия календарей и их цвета, чтобы строки виджета совпадали по цвету с Google Календарём.
  • Разрешение на уведомления — только для напоминания, если не хватает разрешения или авторизации Google.

2. Зачем используются данные

Исключительно для отрисовки виджета на главном экране: чтобы показать события, задачи и дни рождения в хронологическом порядке и обновить их после возврата из другого приложения. Данные не используются для профилирования, маркетинга, рекламы и автоматических решений.

3. Где хранятся данные

Только во внутреннем хранилище приложения на устройстве, недоступном другим приложениям. Задачи и цвета календарей кэшируются в локальный JSON-файл, чтобы виджет рисовался и без сети. На сервер автора ничего не передаётся: сервера, который получал бы эти данные, у автора нет.

4. Сроки хранения и удаление

Локальный кэш обновляется при каждой успешной синхронизации и хранит только текущий список незавершённых задач. Он удаляется вместе с приложением или при очистке его данных в настройках Android. Копий больше нигде не остаётся.

Чтобы удалить данные пользователя Google, напишите на schedule-widget@trmw.ru с темой «Удаление данных». Кроме устройства, копий данных Google у приложения нет, поэтому такой запрос означает очистку этой копии; подтверждение приходит письмом в течение 30 дней. Отзыв доступа приложения на странице myaccount.google.com/permissions сразу прекращает любой дальнейший доступ — после этого новые данные Google не читаются.

5. Передача данных и третьи стороны

Данные не продаются, не передаются и не раскрываются третьим сторонам. Приложение обращается только к API Google (tasks.googleapis.com, www.googleapis.com) с токеном доступа, который выдаёт Google Play services; на этот трафик распространяется политика конфиденциальности Google. В приложении нет рекламных, аналитических, краш-репортинг и прочих сторонних SDK.

Данные пользователя Google никогда не используются для рекламы и ретаргетинга, не продаются и не передаются брокерам данных и перепродавцам информации, не используются для оценки кредитоспособности и кредитных решений и не используются для разработки, улучшения или обучения моделей машинного обучения. Приложение не создаёт и не обрабатывает изображения.

6. Данные пользователя Google и Limited Use

Использование и передача в любое другое приложение информации, полученной от API Google, в ScheduleWidget соответствует Google API Services User Data Policy, включая требования Limited Use.

Конкретно: единственные данные пользователя Google, которые получает приложение, — это данные Google Tasks и список календарей Google из раздела 1. Они запрашиваются с разрешениями только на чтение (tasks.readonly, calendar.calendarlist.readonly), поэтому приложение ничего не создаёт, не меняет и не удаляет в аккаунте Google пользователя. Эти данные нужны только для отрисовки виджета, хранятся только на устройстве, не передаются автору или кому-либо ещё и не читаются людьми.

7. Безопасность

Сетевые запросы идут по HTTPS. Приложение не хранит пароли аккаунта Google и само не работает с долгоживущими refresh-токенами — Google Play services выдаёт короткоживущий токен доступа по запросу. Данные виджета лежат во внутренней песочнице приложения, защищённой песочницей Android; пока устройство заблокировано, их дополнительно защищает файловое шифрование Android.

8. Этот сайт

Сайт — набор статических страниц на GitHub Pages. Он не ставит cookie, не запускает скриптов, не использует аналитику и трекинг и не загружает шрифты, изображения и стили со сторонних сайтов.

9. Права и выбор пользователя

  • Разрешения Android (календарь, контакты, уведомления) можно отозвать в любой момент в Настройки → Приложения → ScheduleWidget → Разрешения; виджет продолжит работать и просто перестанет показывать соответствующие строки.
  • Доступ к Google Tasks и списку календарей отзывается на странице myaccount.google.com/permissions.
  • Удаление данных пользователя Google можно запросить письмом, как описано в разделе 4.
  • Все локально сохранённые данные удаляются вместе с приложением или при очистке его данных в настройках Android.

10. Дети

Приложение не адресовано детям и не обрабатывает сознательно данные детей младше 13 лет.

11. Изменения политики

Если приложение начнёт использовать дополнительные данные, эта страница будет обновлена, а дата «обновлено» выше изменится. Актуальная версия всегда доступна по этому адресу.
