Политика конфиденциальности

English

Приложение ScheduleWidget для Android (пакет com.local.schedulewidget) · обновлено 21 ноября 2026 г.

Здесь описано, какие данные читает приложение ScheduleWidget, зачем, куда они попадают и как отозвать доступ. Приложение личное, у него один пользователь — автор. Учётных записей, регистрации, рекламы и аналитики нет.

1. Какие данные читает приложение

  • Календарь устройства (разрешение READ_CALENDAR) — названия событий, время начала и окончания, признак «весь день», цвета и названия календарей. Нужно для строк событий в виджете.
  • Контакты устройства (разрешение READ_CONTACTS) — только имена и даты контактов, у которых заполнено поле дня рождения. Нужно для строк дней рождения. Номера телефонов, адреса и другие поля контактов не запрашиваются.
  • Google Tasks (разрешение https://www.googleapis.com/auth/tasks.readonly) — названия задач, заметки, сроки и признак выполнения для незавершённых задач в списках пользователя. Нужно для строк задач.
  • Список календарей Google (разрешение https://www.googleapis.com/auth/calendar.calendarlist.readonly) — названия календарей и их цвета, чтобы строки виджета совпадали по цвету с Google Календарём.
  • Разрешение на уведомления — только для напоминания, если не выдано какое-то разрешение или авторизация Google.

2. Как данные используются

Исключительно для отрисовки виджета на домашнем экране устройства: показать события, задачи и дни рождения по времени и обновить их после возврата из другого приложения. Данные не используются для профилирования, рекламы, маркетинга или автоматических решений.

3. Где хранятся данные

Только в приватном хранилище приложения на устройстве, недоступном другим приложениям. Задачи и цвета календарей кэшируются локальным JSON-файлом, чтобы виджет рисовался без сети. На серверы автора ничего не загружается: сервера, который получал бы эти данные, у автора нет.

4. Срок хранения

Локальный кэш обновляется при каждой успешной синхронизации и содержит только текущий список незавершённых задач. Он удаляется при удалении приложения или очистке его данных в настройках Android. Других копий нигде не остаётся.

5. Передача третьим лицам

Данные не продаются, не передаются и не раскрываются третьим лицам. Приложение обращается только к API Google (tasks.googleapis.com, www.googleapis.com) с токеном доступа от Google Play services; этот обмен регулируется политикой конфиденциальности Google. Рекламных, аналитических, краш-репортинг и иных сторонних SDK в приложении нет. Данные Google API не используются для разработки, улучшения или обучения моделей машинного обучения; приложение не создаёт и не обрабатывает изображения.

6. Безопасность

Сетевые запросы идут по HTTPS. Приложение не хранит пароли Google-аккаунта и само не работает с долгоживущими токенами обновления — Google Play services выдаёт короткоживущий токен доступа по запросу. Данные виджета лежат в приватной песочнице приложения и защищены моделью изоляции Android.

7. Ваши права и выбор

  • Разрешения Android (календарь, контакты, уведомления) отзываются в любой момент в Настройки → Приложения → ScheduleWidget → Разрешения; виджет продолжит работать, просто перестанет показывать соответствующие строки.
  • Доступ к Google Tasks и списку календарей отзывается на странице myaccount.google.com/permissions.
  • Все локальные данные удаляются удалением приложения или очисткой его данных в настройках Android.

8. Дети

Приложение не адресовано детям и сознательно не обрабатывает данные детей младше 13 лет.

9. Изменения политики

Если приложение начнёт использовать дополнительные данные, эта страница будет обновлена, а дата «обновлено» вверху изменится. Актуальная версия всегда доступна по этому адресу.
