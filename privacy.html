ScheduleWidget for Android (package com.local.schedulewidget) · last updated 21 November 2026

This policy explains what the ScheduleWidget app reads, why it reads it, where the data goes and how access can be revoked. The app is a personal project with a single user — its author. It has no user accounts, no registration, no advertising and no analytics.

1. Data the app accesses

  • Device calendar (permission READ_CALENDAR) — event titles, start and end times, all-day flags, colours and calendar names. Used to draw the event rows of the widget.
  • Device contacts (permission READ_CONTACTS) — only the names and dates of contacts whose birthday field is filled in. Used to show birthday rows. Phone numbers, addresses and other contact fields are never requested.
  • Google Tasks (scope https://www.googleapis.com/auth/tasks.readonly) — task titles, notes, due dates and completion status of unfinished tasks in the user's task lists. Used to draw the task rows.
  • Google calendar list (scope https://www.googleapis.com/auth/calendar.calendarlist.readonly) — calendar names and their colours, so widget rows match the colours used in Google Calendar.
  • Notification permission — used only to show a reminder when a permission or a Google authorization is missing.

2. How the data is used

Exclusively to render the widget on the device home screen: to show events, tasks and birthdays in chronological order and to refresh them after the user returns from another app. The data is not used for profiling, marketing, advertising or any automated decision-making.

3. Where the data is stored

Only in the app's private storage on the device, which is not readable by other apps. Tasks and calendar colours are cached as a local JSON file so the widget can be drawn while offline. Nothing is uploaded to a server operated by the author: the author has no server that receives this data.

4. Retention

The local cache is refreshed on every successful sync and keeps only the current list of unfinished tasks. It is deleted when the app is uninstalled or its storage is cleared in Android settings. No copy is retained anywhere else.

5. Sharing and third parties

Data is not sold, shared, transferred or disclosed to any third party. The app communicates only with Google APIs (tasks.googleapis.com, www.googleapis.com) using an access token issued by Google Play services; that traffic is subject to Google's own privacy policy. The app contains no advertising, analytics, crash-reporting or other third-party SDKs. Google API data is not used to develop, improve or train machine-learning models, and the app does not generate or process imagery of any kind.

6. Security

Network requests use HTTPS. The app never stores Google account passwords and never handles long-lived refresh tokens itself — Google Play services issues a short-lived access token on demand. Widget data is kept in the app's private sandbox, protected by the Android application sandbox.

7. Your choices and rights

  • Android permissions (calendar, contacts, notifications) can be revoked at any time in Settings → Apps → ScheduleWidget → Permissions; the widget keeps working and simply stops showing the affected rows.
  • Access to Google Tasks and the calendar list can be revoked at myaccount.google.com/permissions.
  • All locally stored data is removed by uninstalling the app or clearing its storage in Android settings.

8. Children

The app is not directed to children and does not knowingly process data of children under 13.

9. Changes to this policy

If the app starts to use additional data, this page will be updated and the "last updated" date above will change. The current version is always available at this address.
